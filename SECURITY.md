# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability:

1. **DO NOT** open a public issue
2. Send email to: mdr702@github.com
3. Or use GitHub Private Reporting

## Supported Versions

Latest version only.

## Response Time

- Acknowledgment: 48 hours
- Fix: 7-14 days
