۵. عملگرهای پایه
ریاضی: + - * / // % **

مقایسه‌ای: == != > < >= <=

منطقی: and or not

مثال:

python
a = 10
b = 3
print(a + b)   # 13
print(a // b)  # 3
print(a % b)   # 1
۶. شرط‌ها (if, else, elif)
python
score = float(input("نمره خود را وارد کنید: "))

if score >= 18:
    print("عالی")
elif score >= 12:
    print("خوب")
else:
    print("نیاز به تلاش بیشتر")
تمرین‌های پیشنهادی
برنامه‌ای بنویسید که دو عدد از کاربر بگیرد و حاصل جمع، تفریق، ضرب و تقسیم را چاپ کند.

برنامه‌ای بنویسید که سن کاربر را بگیرد و تشخیص دهد کودک (کمتر از ۱۲)، نوجوان (۱۲ تا ۱۸) یا بزرگسال (بیشتر از ۱۸) است.

برنامه‌ای بنویسید که یک عدد بگیرد و زوج یا فرد بودن آن را مشخص کند.
